# Class icons

The official AION 2 class icons, so the classes look the same as in the game. The artwork belongs to NCSOFT
(AION 2). The files come from [HamMeter-Aion2](https://github.com/NennMichSchinken/HamMeter-Aion2) (GPL-3.0), where
`brawler.png` was scaled down to the 40×42 of the other icons.
